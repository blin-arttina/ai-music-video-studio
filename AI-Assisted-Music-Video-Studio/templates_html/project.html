Save a Copy to Your Own Device

    
"Export Complete Project (ZIP)" below downloads everything in this
      project — media, saved text, and Timeline — as one file, using your browser's normal
      download. From there, it's yours to keep anywhere you like:

    
    
      
  • Internal storage — it's already in your device's Downloads
        folder as soon as the download finishes; move it with your file manager app if
        you want it somewhere else.
    • 
      
  • Google Drive, Dropbox, or Google One — open that app, choose
        "Upload" (or use your file manager's "Share" / "Save to" option on the downloaded
        ZIP), and pick it from your Downloads folder.
    • 
    

    
This app doesn't connect to those services directly — you choose
      where the file goes, using the apps you already have installed. "Import Project
      (ZIP)" on the Main Menu brings a saved copy back in later, on this device or any
      other.
